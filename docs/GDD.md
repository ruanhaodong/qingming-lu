# 《青冥录》游戏设计文档

像素等距（斜 45°，2:1 菱形格）修仙网页游戏。基调：古典仙侠，略暗的青绿山色。全部界面与对白使用简体中文。

引擎：Phaser 4.2.1。特效：PixelFX 0.3.0 实时合成（风压、释放、命中停顿、受击反应、收势、震屏）。分辨率 640×360，整数倍放大，像素风。交互全部画在 Canvas 上，不使用 DOM 覆盖层。

发现后可通过大世界地图快速旅行。昼夜与天气（雨、雾、萤火、神光）用 PixelFX weather 表现。随机事件：灵气潮漏、秘境开启、魔兽潮、散修斗法、拍卖奇珍、劫云压顶。

副本：

1. **青石矿洞**（前期）：多房间、精英小股、首领「矿脉守护·铁颚妖」，宝箱。
2. **残照地宫**（中期）：房间推进、精英、首领「残照剑灵·幽衡」，宝箱。

## 境界

十境，每境四阶：前期 / 中期 / 后期 / 圆满。

炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫 → 真仙。

突破消耗灵气/修为；中高阶需丹药或渡劫检定。成功时播放 holy / level-up / sunburst 等 PixelFX。

## 法宝与掉落

品类（低到高）：法器、灵宝、法宝、本命法宝、通天灵宝、玄天至宝。  
品阶：凡品、黄品、玄品、地品、天品。  
槽位：武器、防具、饰品、法宝。拾取播放 loot-beam / chest-open / gem-spin。

## 灵兽

种类：傀儡、灵宠、异兽、神兽。流程：削弱后以拘灵符封印。召唤/捕捉用 spawn / summon / portal。出战则跟随并参战。

## 技能

来源：传承（门派/师尊）、学习（功法秘籍）、武器携带。可拆分、合成、以两门已学技能创出新技（重混色板并绑定 PixelFX）。战斗必须遵循 PixelFX 演出节奏。

原创技能特效：青冥剑气、掌心雷、护体真气、丹火炼魄、御剑术、符篆禁制。

## 门派与阵营

门派：青冥宗（正道剑修）、烈焰谷（丹火）、玄霜宫（冰符）、血剑楼（魔道剑杀）。入派获得传承与声望。

阵营：正道、魔道、散修。影响物价、任务与部分敌对。

## 炼器与炼丹

炼器可提升法器品阶/逼近更高境界；炼丹产出修炼、疗伤、捕捉、抗劫丹药。材料来自野外与副本。

## 任务、拍卖、交易

起始区域有主线与支线。望海坊拍卖行可对战利品表生成的挂单出价或一口价。村镇与坊市 NPC 可交易。完成任务与收钱播放 quest-complete / coin-collect。

## 开局与存档

新游戏可改名（默认「青行」），一名灵根驳杂的青冥村少年，炼气前期出生于村外。可行走、对话、接任务、战斗、拾取、修炼，并自然发现其余系统。打坐时若已得「青泉残韵」，只略微精炼灵气，不能改命。localStorage 自动存档。
